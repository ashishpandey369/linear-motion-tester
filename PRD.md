# Product Requirements Document

## Project Name

Linear Counter

---

## Objective

Design and develop a linear reciprocating motion testing machine capable of generating controlled up-and-down motion using a cam mechanism driven by a high-torque NEMA17 stepper motor.

---

## Features

- Adjustable RPM using potentiometer
- Live Frequency Display
- Live RPM Display
- Live Cycle Counter
- Start Button
- Stop Button
- Reset Button
- 24V Powered
- ESP32 Controller

---

## Target Users

- Engineering Students
- Testing Laboratories
- Research Engineers
- Product Development Teams

---

## Hardware

- ESP32
- TB6600
- NEMA17
- TFT Display
- Potentiometer

---
